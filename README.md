# CredX Goa 

> **Centralized Proof-of-Skill & Opportunities Index for Technical Institutions**  
> Developed by **Team Pentabyte** (RIT Goa)

---

## Overview
CredX Goa connects students, faculty in-charges, and government-affiliated entities into a structured, tamper-resistant talent network. By standardizing evaluation across academic CGPA (40%), verified hackathon wins (30%), and technical coursework (30%), the platform highlights practical builders across all Goa engineering colleges on an objective, unified state leaderboard.

## Key Features
- **Dual-Tier Dynamic Leaderboard:** Seamlessly switch between intra-college department rankings and state-wide standings.
- **Faculty Verification Workspace:** RBAC-authenticated portals for designated college faculty in-charges to validate certificate uploads.
- **AI Opportunity Radar:** Personalized recommendation engine for upcoming state/national coding competitions and proactive deadline notifications.
- **Institutional Recruiter Gateway:** Anonymized, privacy-safe talent discovery for verified industry recruiters.

## Tech Stack
- **Frontend:** Next.js (App Router), React, Tailwind CSS, Lucide React
- **Backend:** Python, FastAPI, Pydantic
- **Database:** MongoDB
- **UI Prototyping:** v0 by Vercel
